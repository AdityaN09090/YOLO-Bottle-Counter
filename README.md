# YOLO-Bottle-Counter
Bottle Counter is a web app that uses a custom-trained YOLO model to detect and count bottles in uploaded images, live camera feeds, and videos. It displays bounding boxes, confidence scores, and video tracking data.
Bottle Counter helps users detect and count bottles in images, camera feeds, and video clips. Its React frontend connects to a FastAPI backend that runs a trained YOLO object-detection model and returns annotated results. Video analysis can display bottle detections, tracking IDs, timestamps, and line-crossing counts.
